# ChatGPT Sites delivery

Use this guidance only when the task is to create or revise HTML in ChatGPT and Sites tools are available. Respect explicit local-only or no-publish requests.

- Keep one canonical HTML source and synchronize the Site from that source. Reuse the existing Site identity when revising.
- Distinguish a local preview from a saved Site version and from a deployed URL. Report which state was actually reached.
- Check the Site after saving or deployment and verify the rendered page. Keep the downloadable/offline HTML deliverable when requested.
- Do not publish private project materials without authorization. Sites is a host capability and is not bundled with this plugin.
